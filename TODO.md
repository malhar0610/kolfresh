# KolFresh Frontend Prototype — To Do

Scope guard: frontend only. Use local mock data and local browser state. No backend, API integration, authentication, database, payment integration, notifications, or live operational functionality is included. Native project ToDo tooling was unavailable, so this local checklist records the confirmed outcomes.

- [x] **Responsive customer storefront:** Build a responsive customer storefront with a clear pre-order model, Kolhapur context, and prominent next-day fulfillment messaging.
- [x] **Mock seafood catalog:** Provide a local mock catalog for fresh fish, prawns, crabs, dried fish, and ready-to-cook products, including category browsing and product details.
- [x] **Product configuration:** Provide product configuration interactions for weight or pack size, price, quantity, and cleaning or cut choices.
- [x] **Ordering window display:** Provide ordering-window status for Monday, Wednesday, and Saturday from 8:00 AM to 6:00 PM IST, with browsing and cart building available outside the window plus a clearly labeled prototype reminder affordance.
- [x] **Cart and coupon demo:** Provide a frontend-only cart with editable selections, item totals, coupon-code demo behavior, and an order summary.
- [x] **Checkout demo:** Provide a prototype checkout flow that prevents completion outside the ordering window and clearly labels ordering and payment interactions as non-live.
- [x] **Fulfillment options:** Provide delivery or pickup selection with serviceability demo, exact next-calendar-day fulfillment date, and delivery slots of 5–7 PM or 7–9 PM.
- [x] **Order views:** Provide mock order confirmation, order history, and delivery-tracking concepts, explicitly identified as prototype views without live tracking.
- [x] **Language affordances:** Provide English, Marathi, and Hindi language affordances for the customer experience, implemented with frontend-only controls and representative localized interface text.
- [x] **Optional operations view:** Kept optional admin and delivery operations screens out of scope to preserve the requested simple customer storefront; no real operational functions are present.
